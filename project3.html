[ 04 ] BACKEND / RELATIONAL DATA

Financial Portfolio System

A database and ingestion prototype exploring how market data, investment records, and financial reporting fit together.

PythonMySQLSQLyfinance

Inside the project.

  • Defined MySQL tables for users, financial instruments, investments, market history, and reports. Foreign keys link holdings and daily prices to their instrument records.
  • Wrote a Python ingestion script for historical daily OHLCV data across 25 configured stock tickers, using parameterized database inserts. Each instrument's stored current price is the latest downloaded daily close, not a streaming quote.
  • Added analytical SQL queries covering invested capital, holdings, price comparisons, volume, and daily price ranges.

SCOPE / CONTEXT

What this work represents.

A schema, ingestion script, and analytical-query prototype. It does not include a deployed application, authentication service, live streaming feed, or portfolio optimizer.
