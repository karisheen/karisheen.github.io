[ 07 ] SPEECH / API INTEGRATION

COVID Voice Assistant

An early Python experiment connecting spoken questions to public-health statistics and spoken answers.

PythonParseHubSpeechRecognitionpyttsx3

Inside the project.

  • Retrieved aggregate and country-level COVID statistics through the ParseHub API.
  • Connected Google-backed speech recognition to fixed-pattern question matching and pyttsx3 text-to-speech.
  • Added a spoken refresh command that triggers a ParseHub run and polls for updated data in a background thread.

SCOPE / CONTEXT

What this work represents.

A historical integration project, not a currently maintained public-health service. It depends on an external ParseHub configuration and speech-recognition service; current data availability is not guaranteed.
